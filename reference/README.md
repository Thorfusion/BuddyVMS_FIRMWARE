# Original CC2 Reference Pack

This directory contains only original-board artifacts and component data
sheets useful for replacement firmware:

| File | Purpose |
|---|---|
| `CC2_190430.hex` | Known original application image and behavioral truth |
| `Schematic_Buddy_2026-07-05.png` | Supplied X1-X5 connector drawing; dashboard omitted |
| `infineon-xc87x-ds-en.pdf` | XC87x MCU data sheet |
| `adg408_409.pdf` | ADG408/ADG409 analog multiplexer data sheet |
| `doc3368.pdf` | AT25128A-compatible serial EEPROM data sheet |
| `m24c02-r.pdf` | M24C02 display EEPROM data sheet |
| `SP3222E_SP3232E.pdf` | Serial transceiver data sheet |
| `C7466000.pdf` | Locally supplied display-related component reference; identify against board marking before use |
| `SHA256SUMS.txt` | Integrity hashes for this exact local reference set |

The component PDFs are references, not permission to assume every optional
feature or electrical rating is used exactly as shown in a typical application
circuit. Confirm the populated board.
